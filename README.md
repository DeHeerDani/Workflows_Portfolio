# Workflows Portfolio

Dit project is onderdeel van mijn Workflows Portfolio binnen de opleiding Data Science.

Het portfolio bevat verschillende opdrachten en analyses die zijn uitgewerkt in R. De bestanden laten zien hoe data wordt verwerkt, geanalyseerd en gevisualiseerd met behulp van R en bijbehorende packages.

## Inhoud
De map bevat uitgewerkte opdrachten en bijbehorende bestanden zoals scripts, RMarkdown-bestanden en resultaten.

## Gebruik
Alle analyses zijn uitgevoerd in R. Er is geen extra installatie nodig behalve een standaard werkende R/RStudio omgeving met de gebruikte packages indien nodig.
